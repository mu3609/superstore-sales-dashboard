# SuperStore Sales Dashboard

## Project Overview

This project analyzes SuperStore sales data using Power BI to understand sales performance, profitability, customer segments, product categories, order trends, and shipping performance.

## Business Problem

The objective was to transform raw retail data into an interactive dashboard that can help users monitor business KPIs and explore sales and profit performance across multiple dimensions.

## Tools Used

- Power BI
- Power Query
- DAX
- Excel
- Data Modeling
- Data Visualization

## Data Cleaning & Preparation

- Checked for missing and inconsistent values.
- Verified data types.
- Prepared and transformed data using Power Query.
- Organized date-related fields for time-based analysis.
- Prepared the cleaned dataset for reporting.

## Key KPIs

- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Average Shipping Days

## Dashboard Analysis

The dashboard provides analysis across:

- Category
- Sub-Category
- Customer Segment
- Region
- Year
- Month
- Ship Mode
- Product Performance

## Dashboard Features

- Year filter
- Region filter
- Category filter
- KPI cards
- Monthly trend analysis
- Sales and profit comparison
- Sub-category analysis
- Shipping analysis

## Key Observations

- Sales and profitability can be explored across region, category, and time.
- Sub-category performance varies and should be evaluated separately from overall category performance.
- Monthly sales trends show variation across periods.
- Customer segment analysis helps compare revenue contribution from different customer groups.
- Shipping analysis provides an additional operational view of order activity.

## Business Recommendations

- Investigate low-profit product areas.
- Monitor sales seasonality.
- Compare customer segments for stronger revenue opportunities.
- Evaluate products using both sales and profitability.
- Use shipping analysis alongside sales performance when reviewing operations.
