# SuperStore Sales Dashboard

## Project Overview

This project analyzes SuperStore sales data using Power BI to understand sales performance, profitability, customer segments, product categories, and order trends.

The goal of the dashboard is to convert raw sales data into clear business insights that can support better decision-making.

## Tools Used

- Power BI
- Power Query
- DAX
- Excel
- Data Visualization

## Key KPIs

- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Sales by Category
- Profit by Sub-Category
- Sales by Customer Segment
- Monthly Sales Trends
- Shipping Mode Performance

## Dashboard Analysis

The dashboard provides analysis across:

- Product categories and sub-categories
- Customer segments
- Sales and profit performance
- Monthly and yearly sales trends
- Shipping modes
- Order performance
